# DIR ECHOES · Voice Router

Голосовой маршрутизатор обращений для контакт-центра. Проект команды **DIR ECHOES** для кейса Halyk Bank на HackAlem AI.

**Статус: требования и архитектура изучены; реализация начинается.** Этот README не заявляет готовность ещё не реализованных функций. Проверенные возможности, команды запуска, результаты оценки и адрес развёрнутой версии будут добавляться вместе с кодом.

## Задача

Понять свободную речь клиента на русском и казахском, выбрать один или несколько из 40 сценариев, сохранить контекст при смене темы и дать голосовой ответ на основании предоставленных данных. Супервизор должен видеть сценарий, краткое обоснование, альтернативы и фактическое время каждого этапа.

## Основа решения

- LLM принимает содержательное решение о маршрутизации и извлекает параметры.
- Сервер проверяет результат, собирает недостающие данные и исполняет разрешённые действия.
- Необратимые действия требуют подтверждения конкретных параметров операции.
- PostgreSQL сохраняет разговоры, действия, изменения сущностей и очередь операторов.
- Голосовой ввод и ответ используют реальные STT/TTS API; текст остаётся резервным каналом.

## Данные и границы

Заказчик предоставил набор **Saqta Insurance**, версия 1.0, дата среза 2026-10-01. Компания и записи вымышлены по условиям кейса. Пользователь подтвердил использование этого набора. Работа платформы, запросы к моделям и сохранение результатов должны быть реальными; интеграция с продуктивной системой страховой компании не предоставлена.

Исходный набор не публикуется автоматически. Предусматривается импорт из отдельного каталога; правила доступа и происхождение сохраняются. Нельзя подставлять ответы из проверочного набора вместо маршрутизации.

## Безопасность

Ключи используются только сервером, исключены из Git и браузерного кода. Пример настроек не содержит секретов. Доступ к истории, данным и очередям должен проверяться сервером. Публичный URL сам по себе не даёт доступа к данным контакт-центра.
