PNG-версии используются в основном README для надёжного отображения на GitHub. PPTX содержит оригинальные снимки как изображения, а обозначения и текст остаются отдельными объектами.

В снимках нет ключей, кодов доступа и реальных персональных данных. Счётчики в Supervisor Live отражают состояние локальной базы в момент съёмки. Они не являются сравнением моделей или измерением производительности текущего релиза. Видимый интерфейс не доказывает живую слышимость, работу микрофона или WebRTC между двумя устройствами.
